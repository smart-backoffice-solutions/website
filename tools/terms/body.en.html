The personal data processed differ per document. The table below indicates for each document category (i) which documents fall within the category concerned and (ii) which personal data Processor processes for these documents.

Document category Documents Personal data processed

General

All

  • Age, gender, marital status

Identification documents

Passport, identity card, residence permit, etc.
  • Data relating to an identity document and data relating to any residence permit

Income documents

Employer’s statement, payslip, Chamber of Commerce (KvK) extract, self-employed income statement
  • Data about the employment, the business and the income;
  • any loans via the employer (e.g. a company bicycle paid in instalments)
  • Data concerning health – e.g. when the payslip indicates sick leave

Asset documents

Bank statements, financing overview
  • Data about assets

  • Data about financial products taken out such as, but not limited to: a bank account, a student loan, lease contracts, other loans taken out.

Property data

  • Data about the property to be purchased
  • Data about the purchase such as purchase price, notary, transfer date, bank guarantee

  • All personal data described above
